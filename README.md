# Shubham Kuthe — Portfolio 2026

Live: https://shubhamkuthe.github.io/

Plain HTML/CSS/JS. No build step: open `index.html` in a browser, or use VS Code's Live Server.

## Files
- `index.html` — all content (text, projects, links, chat bot)
- `css/style.css` — design (black & white, layout, responsive)
- `js/main.js` — animations (preloader, hero, morph, project scenes, cursor, LEGO bot)
- `vendor/` — GSAP, ScrollTrigger, Lenis (local copies)
- `assets/` — LEGO figure, bot avatar, about photo, link-preview image, app icon
- `favicon.ico`, `favicon-32.png`, `apple-touch-icon.png` — browser tab / home screen icons
- `Shubham-Kuthe-Resume.pdf` — CV behind the "Download CV" button
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Deploy (GitHub Pages)
Push the contents of this folder to the root of the `ShubhamKuthe/shubhamkuthe.github.io` repo, branch `main`.
Pages serves it at https://shubhamkuthe.github.io/ within a minute or two.

## Link previews
After going live, paste the URL into https://www.linkedin.com/post-inspector/ once so LinkedIn refreshes its cached preview.
